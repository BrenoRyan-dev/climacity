🌤️ Clima City

O Clima City é uma aplicação web desenvolvida para consultar informações meteorológicas de cidades em tempo real.

O projeto permite pesquisar uma cidade e visualizar informações sobre as condições climáticas atuais, além de possibilitar o salvamento de cidades favoritas para facilitar futuras consultas.

🚀 Funcionalidades
🔎 Pesquisa de cidades
🌡️ Consulta do clima em tempo real
☁️ Exibição das condições climáticas atuais
⭐ Salvamento de cidades favoritas
📱 Interface responsiva para diferentes dispositivos
🔄 Consumo de API de dados meteorológicos
🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript
React
API de clima
📚 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar desenvolvimento web, integração com APIs, manipulação de dados e construção de interfaces utilizando React.
